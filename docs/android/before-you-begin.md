# Getting Started

Have these ready before you start:

- **Android phone or tablet** with the VigyanShaala app installed
- **Sign up or log in** — [Public Signup](logging-in.md#create-account) or [log in](logging-in.md#log-in)
- **Email inbox** — for activation and password reset links
- **Stable internet** — for videos and live sessions; [download content](inside-a-program.md#downloads) when available

Use the bottom tabs — **Explore**, **My Learning**, and **Profile** — for each task.
