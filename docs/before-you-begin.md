# Getting Started

Have these ready before you start:

- **Platform URL** — [https://mycommunity.vigyanshaala.com/](https://mycommunity.vigyanshaala.com/){ target="_blank" }
- **Sign up or log in** — [Create your account](logging-in.md#create-account), [email](logging-in.md#log-in), or [mobile](logging-in.md#log-in-mobile)
- **Email inbox** — for activation and password reset links
- **Phone number** — only for the Log In **Mobile** tab (not asked at sign-up)
- **Browser** — Chrome or Edge recommended
- **Stable internet** — especially for live sessions

Use the left menu for each task — browse programs, apply, learn, and track progress.
